# Свояк — викторина по Wi‑Fi

Ведущий управляет игрой с телефона, у каждого игрока на телефоне своя кнопка.
Можно вывести табло на телевизор или ноутбук.

## Онлайн, без ноутбука и сервера (подходит для iPhone)

Откройте на телефоне ведущего ссылку на `host.html` (её даёт Claude, или включите GitHub Pages —
Settings → Pages → ветка `claude/svoyak-game`, и откройте `…/svoyak/public/host.html`).

- Телефон ведущего сам становится «сервером»: создаётся комната с кодом и QR-кодом.
- Игроки сканируют QR или открывают ссылку и вводят имя. Нужен интернет, сеть у всех может быть разная.
- Не закрывайте вкладку и не сворачивайте Safari надолго — игра живёт на телефоне ведущего.
  Если свернули — при возвращении всё переподключится само, счёт сохранится.
- PIN на пульте нужен для второго пульта и шпаргалки с ответами на другом устройстве.
- Связь идёт через бесплатные публичные MQTT-серверы (EMQX, HiveMQ, Mosquitto) — сразу через все, работает тот, что доступен.

## Запуск в локальной сети

Сервер запускается на **одном** устройстве в той же Wi‑Fi сети, что и все игроки.

**Ноутбук (Windows / macOS / Linux)**
1. Установите Node.js 18 или новее: https://nodejs.org
2. Скачайте папку `svoyak` (на GitHub: Code → Download ZIP).
3. В папке `svoyak` выполните: `node server.js`

**Android-телефон (через Termux)**
```
pkg install nodejs git
git clone https://github.com/eger1401/qaapr22-kunchenkoegor.git
cd qaapr22-kunchenkoegor && git checkout claude/svoyak-game && cd svoyak
node server.js
```

**Только телефон, без ноутбука (Android)**
Сервер и пульт работают на одном телефоне ведущего:
1. Поставьте Termux из F-Droid (версия из Google Play устарела) и выполните команды выше (один раз, нужен интернет).
2. Дальше каждый раз: откройте Termux, `cd qaapr22-kunchenkoegor/svoyak && termux-wake-lock && node server.js`.
   `termux-wake-lock` не даёт Android усыпить сервер, когда вы переключаетесь в браузер.
3. В браузере на этом же телефоне откройте `http://localhost:3000/host`.
4. Игроки подключаются к тому же Wi‑Fi и открывают адрес `…/play`, который показал сервер.

Если Wi‑Fi чужой (кафе, гостевая сеть), телефоны в нём часто не видят друг друга.
Тогда включите **точку доступа** на телефоне ведущего и подключите к ней всех — интернет для игры не нужен.
После включения точки доступа перезапустите сервер, чтобы он показал новый адрес.

На iPhone сервер запустить нельзя, но iPhone отлично подходит как пульт и как телефон игрока.

Сервер напишет адреса и PIN ведущего, например:

```
Игроки:          http://192.168.1.5:3000/play
Ведущий:         http://192.168.1.5:3000/host   PIN: 4821
Большой экран:   http://192.168.1.5:3000/screen
```

Если телефоны не открывают адрес — разрешите Node.js в брандмауэре (Windows спросит при первом запуске)
и проверьте, что все в одной сети. Можно раздать Wi‑Fi с телефона ведущего.

Свой PIN или порт: `HOST_PIN=1111 PORT=8080 node server.js`.
Сразу начать с другим пакетом: `PACK=classic node server.js`.

## Трансляция на ТВ

**Лучший вариант — открыть `…/screen` прямо на телевизоре** (в браузере Smart TV) или на ноутбуке,
подключённом к ТВ. Тогда пульт остаётся только у вас в руках.

**Если транслируете экран своего телефона**, включите на пульте «Трансляция: вкл». В этом режиме:
- ответ скрыт — чтобы подсмотреть, зажмите кнопку «Держите, чтобы подсмотреть ответ»
  (пока держите, ответ виден и на ТВ, так что делайте это быстро или отвернув экран);
- скрыты PIN, журнал, ставки в финале и отметки «кота в мешке» на табло.

Удобнее всего держать ответы на втором устройстве: откройте `…/cheat` (по PIN) на другом телефоне
или планшете — там все вопросы и ответы текущего пакета.

## Как играть

1. Игроки открывают `/play` и вводят имя. Ведущий входит в `/host` по PIN и жмёт «Начать игру».
2. Игрок, который выбирает, называет тему и цену. Ведущий нажимает эту клетку — вопрос появляется у всех.
3. Ведущий читает вопрос и жмёт «Открыть кнопку». Кто первым нажмёт, тот отвечает.
   Нажал раньше — кнопка блокируется на 1 секунду.
4. «Верно» — игрок получает очки и выбирает следующий вопрос. «Неверно» — теряет очки, кнопка открывается для остальных.
5. **Кот в мешке** (на пульте отмечен рамкой): кнопки нет, ведущий сам выбирает, кто отвечает.
6. После раундов — **финал**: игроки с плюсовым счётом делают ставки, пишут ответ на телефоне, ведущий отмечает верные.

Ведущий может в любой момент поправить счёт (кнопка ⋯ у игрока), назначить выбирающего, перейти к любому раунду.
Игра сохраняется в `data/state.json`: если сервер перезапустить, она продолжится.
Если игрок перезагрузил страницу, он вернётся в игру со своим счётом.

## Мои вопросы (картинки мемов и видео с YouTube)

На пульте: «Мои вопросы» → название темы, до 5 вопросов. К вопросу можно добавить ссылку на картинку (https://…)
и/или ссылку на YouTube с секундами «с … до …» — клип остановится, например, прямо перед вирусной фразой,
а после ответа его можно досмотреть («▶ Досмотреть»). Видео играет на большом экране, а если его нет —
на телефоне ведущего (при трансляции — на ТВ). Свои темы попадают в следующую игру первыми.
В пакете поле выглядит так: `"video": { "id": "dQw4w9WgXcQ", "start": 43, "end": 52 }`.

## Кнопка

Нажатия собираются 0,45 секунды после первого, и побеждает самая быстрая реакция — время от момента,
когда кнопка загорелась у конкретного игрока, до нажатия. Так медленный интернет не мешает.
Все сообщения идут сразу через несколько серверов связи — телефон берёт то, что пришло раньше.

### Картинки и музыка

Положите файлы в папку `media/` и укажите их в вопросе:

```json
{ "price": 300, "text": "Угадайте песню", "answer": "…", "audio": "pesnya1.mp3" }
{ "price": 200, "text": "Чей это логотип?", "answer": "…", "image": "logo1.png" }
```

Ещё есть поля `"big": "🦁👑"` (крупные эмодзи) и `"melody": "E5/1 B4/.5 …", "bpm": 150` (мелодия нотами,
играется без файлов: нота/длительность в долях, `-` — пауза). Картинки флагов и карт генерирует `tools/build-media.js`.

Картинка показывается у всех. Музыку ведущий включает кнопкой «▶ Музыка»: она играет на большом экране
(`/screen`; там один раз нажмите «Включить звук»), а если экран не открыт — на телефоне ведущего.
Так можно собрать настоящую «Угадай мелодию» из своих mp3.

## Формат пакета

```json
{
  "title": "Свояк",
  "rounds": [
    {
      "name": "Первый раунд",
      "themes": [
        {
          "name": "География",
          "questions": [
            { "price": 100, "text": "Столица Австралии.", "answer": "Канберра" },
            { "price": 200, "text": "…", "answer": "…", "type": "cat" }
          ]
        }
      ]
    }
  ],
  "final": { "theme": "Космос", "text": "…", "answer": "…" }
}
```

Бонусы раскладываются случайно: **1–2 больших и 1–2 мелких на раунд**, большие в разных раундах — разные.
В финале ответ отправляется один раз — изменить его нельзя.
Вопросы одноразовые: в «Случайном миксе» один и тот же вопрос не встретится дважды, пока не сыграны все.

**Финал** в «Случайном миксе»: 20 тем на выбор. Финалисты (у кого счёт больше нуля) по очереди убирают темы
у себя на телефонах, начиная с того, у кого меньше очков; ведущий может убрать тему за игрока.
Последняя оставшаяся тема — финальный вопрос: ставки, ответ на телефоне, ведущий отмечает верные.
Игроки видят только надпись «Бонус» — какой именно, становится видно, когда кто-то нажал кнопку.
Ответить должны все: на пульте видно, кто ещё не отвечал, ведущий может вызвать любого;
пропустить вопрос можно только кнопкой ведущего «Никто не ответил».
Бонус достаётся тому, кто первым нажал кнопку (кроме кота в мешке):
- **Быстрые баллы** (мелкий) — кто первым нажал, получает +50…+300;
- **Удача** (мелкий) — выбравший сразу получает +50…+300;
- **Попроси баллы** — карточка вместо вопроса: нажавший просит у ведущего баллы, ведущий решает, сколько дать;
- **Отвечай приблизительно** — засчитывается и примерный ответ;
- **Без риска** — верно ×2, ошибка без минуса;
- **Плюс на минус** — карточка вместо вопроса: у нажавшего счёт меняет знак (+300 → −300, −300 → +300);
- **Кот в мешке** — кнопки нет, выбравший передаёт вопрос другому; текст вопроса появляется только после передачи.

Раундов, тем и вопросов может быть сколько угодно. Поле `"type"` в вопросах сейчас не используется — бонусы случайные:
- `"cat"` — кот в мешке: вопрос передают другому игроку, кнопки нет; сам вопрос игроки видят только после передачи;
- `"norisk"` — без риска: отвечает выбравший, верно ×2, ошибка без минуса;
- `"plusminus"` — плюс на минус: у первого нажавшего счёт меняет знак.
